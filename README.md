# Unprepared - Stealth & Theft RPG

A 3D immersive stealth and theft rpg built with Python and PyOpenGL, featuring dynamic NPC schedules, interactive left-hinge doors, lockpicking mini-games, and a merchant trading system.

## Key Features
- **Dynamic World & Schedule:** NPCs follow daily routines (sleeping, patrolling, shopkeeping) and react to player behavior and crimes.
- **Interactive Environment:** Solid opaque walls, functional left-hinge doors, and a blacksmith's anvil for crafting lockpicks.
- **Trading System:** Expanded merchant inventories with a dedicated UI interface for buying and selling goods.
- **Lockpicking Mini-Game:** Visual lock mechanism featuring real-time rotation feedback and sweet-spot detection.
